3. Create a table “Student” with following structure:

Roll	Name	Age	Course	Math	Physics	Computer
	Birthday


Details of Attributes:-
Roll		Number (5)		
Name		Varchar2 (30)		
Age		Number (5)
Course		Varchar2 (5)			
Math		Number (6, 2)
Physics		Number (6, 2)
Computer	Number (6, 2)
Birthday            Date

Query:
CREATE TABLE Student
(
    Roll NUMBER(5),
    Name VARCHAR2(30),
    Age NUMBER(5),
    Course VARCHAR2(5),
    Math NUMBER(6,2),
    Physics NUMBER(6,2),
    Computer NUMBER(6,2),
    Birthday DATE
);

DESC Student;
